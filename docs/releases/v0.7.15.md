# SaruPDF 0.7.15

- 「ツール (T) → ファイルの場所を開く」を追加しました。開いているPDFの保存先をエクスプローラーで開き、対象ファイルを選択します。
- PDFを開いていない場合は項目を無効にします。名前を付けて保存した後は新しい保存先を開きます。ファイルが削除されていても保存先フォルダーが残っていれば、そのフォルダーを開きます。

Windowsでのビルドは警告0・エラー0を確認しました。Windows 10と実際のインストール先への上書き更新は今回未検証です。

v0.7.12以降は「ヘルプ → 更新」からZIP方式で更新できます。初回導入用インストーラー、更新専用ZIP、それぞれのSHA-256一覧を配布します。
