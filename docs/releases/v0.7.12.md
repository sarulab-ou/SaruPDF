# SaruPDF 0.7.12

- 「ヘルプ (H)」に「バージョン情報」と「更新」を配置しました。実行中のバージョンを確認できます。
- アプリ内更新を更新専用ZIPによる方式へ変更しました。ダウンロードと検証後、未保存の変更を確認して終了し、ファイルを置き換えて再起動します。開いていたPDFも開き直します。
- 置き換えに失敗した場合は退避したファイルへ戻します。ZIP内のパスと全ファイルのSHA-256を検証し、パッケージ外のユーザーファイルを保持します。
- モード切り替え時の倍率復元がPDF読み込み直後に上書きされる場合に、再適用するようにしました。

**v0.7.11以前からこの版への導入だけは従来のインストーラーを使います。v0.7.12以降のアプリ内更新はZIP方式です。** 更新前に未保存の編集を保存してください。

Windows 11で自動テスト103件が成功しました。隔離したフォルダーでファイル置換・再起動・ロック失敗時の復旧を検証し、実際のpublish出力から作成した更新ZIP内の全ファイルも検証しました。実際のインストール先への上書き更新とWindows 10での動作は今回未検証です。

初回導入用の `SaruPDF-0.7.12-Setup-x64.exe` とアプリ内更新専用の `SaruPDF-0.7.12-Update-x64.zip`、それぞれのSHA-256一覧を配布します。EXE／インストーラーは未署名です。
