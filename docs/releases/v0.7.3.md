# SaruPDF 0.7.3

- コメントモードで、2段組と判定できるPDFの読み順を改善しました。同じ段を上から下に選択してから次の段へ進みます。
- 左右の段がPDFの文字抽出で同じブロックや行に混ざる場合も、十分な根拠と段間の隙間があるときは単語単位で分離します。狭い段間の文書にも対応します。
- マウスでの前後両方向のドラッグ、Shiftを使った選択、意図的に段をまたぐ選択を検証しました。複雑なレイアウトや回転ページなど、すべての文書の読み順を保証するものではありません。

Windows 11で自動テスト80件が成功しました。複数段落と狭い段間の再現用PDFに加え、問題が報告された論文PDFでも、左段のドラッグに右段が混ざらないことを原本を変更せずに確認しました。Windows 10での受け入れ確認は未実施です。

`SaruPDF-0.7.3-Setup-x64.exe`で更新してください。更新前にSaruPDFの全ウィンドウを閉じてください。配布物はインストーラーとSHA-256一覧のみです。.NET Runtimeは同梱し、WebView2 Runtimeは別途必要です。EXE／インストーラーは未署名です。
