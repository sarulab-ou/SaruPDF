# SaruPDF 0.7.10

- 「ヘルプ (H) → 更新」からGitHubの最新正式版を確認できます。
- 新しい版がある場合は「ダウンロードして更新」でインストーラーを取得します。進捗表示とキャンセルに対応し、サイズとSHA-256を照合してから更新を開始します。
- すべてのPDFの保存確認を済ませてSaruPDFを終了した後、インストーラーを起動します。保存確認で取り消すとウィンドウと未保存の編集内容を保持します。インストーラーの画面に従って更新してください。
- 起動時の自動確認やバックグラウンドでの定期通信は行いません。

Windows 11で自動テスト101件が成功しました。実際のGitHub配布物のダウンロードとチェックサム照合も確認しています。終了待機と起動の検査には無害なテスト用ファイルを使用しました。今回、既存環境への上書き更新とWindows 10での導入は実行していません。

更新機能はこの版から利用できます。旧版からは `SaruPDF-0.7.10-Setup-x64.exe` をダウンロードし、SaruPDFをすべて閉じて実行してください。配布物はインストーラーとSHA-256一覧のみです。.NET Runtimeは同梱し、WebView2 Runtimeは別途必要です。EXE／インストーラーは未署名です。
