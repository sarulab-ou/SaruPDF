# SaruPDF 0.3.0

- 「編集(E) → 編集モード」を追加しました。左のページ一覧で1ページを切り取り、選択したページの前または末尾へ貼り付けて順番を変更できます。
- Ctrl+Xで切り取り、Ctrl+Vで貼り付け、Ctrl+Zで元に戻す、Ctrl+Yでやり直しができます。
- Ctrl+Sで保存、Ctrl+Shift+Sで名前を付けて保存できます。未保存のまま編集モードを解除したりウィンドウを閉じたりする場合は確認します。
- 切り取り中のページを貼り忘れた保存を防ぎ、編集中に元ファイルが外部で変更された場合は上書きを止めます。

この版は同じPDF内のページ移動に対応します。暗号化・パスワード付きPDFや署名欄のあるPDFは編集できません。本文の文字・画像の編集、別PDFとの結合には対応していません。

自動テスト43件が成功しました。実際の編集ボタン・メニューとCtrl+X/V/Sのコマンド処理、保存後のページ順・WebView2描画、基本的な注釈としおりの参照先を確認しています。保存ダイアログの対話操作、特殊なPDF機能の完全保持、インストーラーの導入・削除の再試験は未実施です。

`SaruPDF-0.3.0-Setup-x64.exe`で更新してください。更新前にはSaruPDFの全ウィンドウを閉じてください。配布はインストーラーとSHA256一覧のみです。.NET Runtimeは同梱、WebView2 Runtimeは別途必要です。EXE／インストーラーは未署名です。
