# SaruPDF 0.2.0

Windows 10 / 11 x64 向けの PDF Viewer です。PDF ごとに独立したウィンドウを表示し、同じ PDF を再び開くと既存のウィンドウへ移ります。

- アプリ名、実行ファイル名を **SaruPDF / SaruPDF.exe** に統一しました。
- 現在のユーザー用のインストーラーとアンインストーラーを追加しました。
- インストール時に PDF を開くアプリの候補登録を選択できます。
- アプリの「設定 → PDF の関連付け」からも登録でき、Windows の既定アプリ設定を開けます。既定アプリの変更は Windows の画面で選択してください。

`SaruPDF-0.2.0-Setup-x64.exe` をダウンロードして実行してください。更新前には、SaruPDF の全ウィンドウを閉じてください。SHA256 検証ファイルも添付しています。

.NET Runtime は同梱しています。**WebView2 Runtime は別途必要**です。不足している場合はアプリに表示される [Microsoft 公式入手先](https://developer.microsoft.com/microsoft-edge/webview2/#download-section)を利用してください。

ビルドは警告・エラー 0、自動テスト 22 件と導入・更新・削除などのセットアップ試験 4 項目が成功しました。既存の PDF 既定設定と、後からインストール先に置いたファイルの保持を確認しています。

EXE／インストーラーは未署名です。Windows 10、WebView2 未導入 PC、Windows 設定で実際に既定アプリを切り替える操作は未確認です。
