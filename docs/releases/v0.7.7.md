# SaruPDF 0.7.7

- Ctrl+Fまたは「編集 → 検索」でPDF本文を検索できます。Enter／Shift+Enter、F3／Shift+F3、「次を検索」／「前を検索」で一致箇所を移動し、末尾から先頭へ循環します。
- Viewモード、ページ操作モード、コメントモードで検索できます。ページ操作・コメントモードでは一致箇所を明るい紫で表示し、Viewモードではビューアー標準の色で表示します。
- 日本語と英語の検索に対応します。編集後は未保存の変更を含む内容を再検索します。画像のみのPDFにはOCRを行いません。

Windows 11で自動テスト89件が成功しました。検索画面、次・前への移動、各モードの表示、未保存の編集後の再検索を確認しています。Windows 10とインストーラーの導入・削除は今回未検証です。

`SaruPDF-0.7.7-Setup-x64.exe`で更新してください。更新前にSaruPDFの全ウィンドウを閉じてください。配布物はインストーラーとSHA-256一覧のみです。.NET Runtimeは同梱し、WebView2 Runtimeは別途必要です。EXE／インストーラーは未署名です。
