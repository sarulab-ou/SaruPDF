# SaruPDF 0.6.0

- 編集モードでCtrl+「+」／Ctrl+「-」による拡大・縮小に対応しました。テンキーの＋／－と、＋の入力にShiftを使うキーボードにも対応します。表示中のページを追従します。
- ページ境界の右クリックメニューに「ここにPDFをインポート…」を追加しました。選んだPDFの全ページをその位置へ挿入し、複数ファイルもまとめて取り込めます。インポート元は変更しません。
- Ctrl+N／「ファイル → 新規ウィンドウ」で、0ページの「無題」編集ウィンドウを作れます。別ウィンドウからの複数ページ貼り付けやPDFインポートに対応し、初回のCtrl+Sで保存先を指定します。余分な白紙ページは追加しません。
- 複数ファイルのインポートを1回のUndoで取り消せます。読み込みに失敗した場合は文書・履歴を変更しません。

ビルドは警告・エラー0、自動テスト60件が成功しました。拡大縮小キー、境界メニューからのインポート、Ctrl+Nで作った文書への貼り付け・保存・閲覧を確認しています。ファイル選択ダイアログの対話操作、物理キー・マウスによる通し操作、Windows 10、インストーラー導入・削除の再試験は未実施です。

`SaruPDF-0.6.0-Setup-x64.exe`で更新してください。更新前にはSaruPDFの全ウィンドウを閉じてください。配布はインストーラーとSHA256一覧のみです。.NET Runtimeは同梱、閲覧モードのWebView2 Runtimeは別途必要です。EXE／インストーラーは未署名です。
