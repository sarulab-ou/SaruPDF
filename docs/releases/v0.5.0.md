# SaruPDF 0.5.0

- 別のPDFから複数ページをまとめてコピー・貼り付けできるようにしました。コピー元と貼り付け先を両方編集モードにし、Ctrl/Shiftでページを選択→Ctrl+C→貼り付け先のページ間を右クリックして「ここに貼り付け」で挿入します。
- 編集メニューと右クリックメニューにもコピーを追加しました。Ctrl+Vでの貼り付け、同じPDF内の複製、繰り返し貼り付け、Undo/Redoにも対応します。
- コピー元は変更せず、コピーした後は元のウィンドウを閉じても利用できます。コピーしたページはSaruPDF内の専用クリップボードで共有し、アプリ終了時に消去します。他のPDFアプリとのページ受け渡しには対応していません。
- 縦横サイズが異なるPDFから貼り付けた場合も表示位置が選択に追従するようにしました。

保存するPDFは画像化しません。コピー元文書全体のしおり・フォーム構造は移植しません。暗号化・パスワード付きPDFや署名欄のあるPDFは編集できません。切り取りは同じPDF内の移動です。

ビルドは警告・エラー0、自動テスト53件が成功しました。コピー元を閉じてからの2ウィンドウ間の複数ページ貼り付け、繰り返し貼り付け、保存後の本文・画像・回転・基本注釈と実描画を確認しています。物理キー・マウスによる実デスクトップ操作、Windows 10、特殊なPDF機能の完全保持、インストーラー導入・削除の再試験は未実施です。

`SaruPDF-0.5.0-Setup-x64.exe`で更新してください。更新前にはSaruPDFの全ウィンドウを閉じてください。配布はインストーラーとSHA256一覧のみです。.NET Runtimeは同梱、閲覧モードのWebView2 Runtimeは別途必要です。EXE／インストーラーは未署名です。
