# SaruPDF 0.7.5

- ページ操作モードで、選択したページを右または左に90度回転できます。編集メニューとページの右クリックメニュー、Ctrl+R／Ctrl+Lから操作できます。
- 複数ページを選択してまとめて回転できます。編集メニューに「全部選択」を追加し、Ctrl+Aでも全ページを選択できます。
- 回転はCtrl+Z／Ctrl+Yで取り消し・やり直しができます。保存後はPDFのページの向きとして保持し、回転したページのコピーや並べ替えにも対応します。

Windows 11で自動テスト84件が成功しました。回転後の画面表示と保存、既存の回転角、複数ページのコピー・並べ替え、Undo／Redo、コメント座標を確認しています。Windows 10とインストーラーの導入・削除は今回未検証です。

`SaruPDF-0.7.5-Setup-x64.exe`で更新してください。更新前にSaruPDFの全ウィンドウを閉じてください。配布物はインストーラーとSHA-256一覧のみです。.NET Runtimeは同梱し、WebView2 Runtimeは別途必要です。EXE／インストーラーは未署名です。
