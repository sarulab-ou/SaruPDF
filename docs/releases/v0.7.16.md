# SaruPDF 0.7.16

- アプリの更新後、開いていたPDFごとにモード・倍率・表示位置を復元します。
- ウィンドウの位置・サイズ・最大化、コメントモードのキャレットと選択範囲も引き継ぎます。
- 複数PDFを個別に復元し、開けないファイルがあっても残りのPDFを開きます。未保存の変更は更新前に保存・破棄・取消を確認します。

表示状態を引き継げるのはv0.7.16以降から行う更新です。v0.7.15以前から今回の版へ更新するときは、従来どおりPDFの再オープンのみになります。

Windowsで自動テスト108件が成功しました。全モードの倍率・表示位置の復元、コメントの選択範囲、日本語を含むパス、インスタンス間の引き継ぎ、ZIPの置換・再起動・失敗時の復旧を確認しています。実際のインストール先への上書き更新と、Windows 10での動作は今回未検証です。

初回導入用インストーラー、更新専用ZIP、それぞれのSHA-256一覧を配布します。v0.7.12以降は「ヘルプ → 更新」からZIP方式で更新できます。
