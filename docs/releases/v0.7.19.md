# SaruPDF 0.7.19

- 他のアプリで作成されたハイライトのコメントも、SaruPDFで追加したコメントと同じ7 ptの赤字で表示します。View・ページ操作・コメントの全モードに対応します。
- 元のハイライトや作成者情報を保持し、開くだけではPDFを書き換えません。外部コメントは読み取り表示し、SaruPDFの編集可能な注釈へ変換しません。
- Viewモードの赤字はスクロールとズームに追従し、マウス操作を妨げません。Popupを重複表示せず、非表示の注釈とSaruPDFで作成した注釈の二重描画を避けます。

Windowsで自動テスト111件が成功しました。外部コメントの英語・日本語の赤字描画、元の注釈の保持、ページ回転後の保存、既存機能の回帰試験を確認しています。Windows 10と実際のインストール先への上書き更新は今回未検証です。

初回導入用インストーラー、更新専用ZIP、それぞれのSHA-256一覧を配布します。「ヘルプ → 更新」から更新できます。
