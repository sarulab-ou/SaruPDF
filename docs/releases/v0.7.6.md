# SaruPDF 0.7.6

- 赤字コメントを7 ptの明朝体に変更し、ハイライトに重ねて読みやすく表示します。
- 複数行のコメントは、対応するハイライト行の先頭と高さに合わせて配置します。段落の幅を推定して折り返し、ハイライトの行数を超える場合は同じ段の次の行へ続けます。
- 段落の幅をコメント注釈に保存するため、PDFを保存して開き直した後も配置を保持します。従来のSaruPDFコメントも、コメントモードで「名前を付けて保存」すると新しい表示に更新できます。
- 英語は単語の区切りを優先して折り返します。複雑な段組みや文字情報のないPDFなど、段落が判定できない場合はページ幅を使用します。

Windows 11で自動テスト87件が成功しました。7 ptの日本語・英語コメント、複数行の位置、段落領域の保存・再読込、旧コメントの領域推定、および別の描画エンジンでの表示を確認しています。Windows 10とインストーラーの導入・削除は今回未検証です。

`SaruPDF-0.7.6-Setup-x64.exe`で更新してください。更新前にSaruPDFの全ウィンドウを閉じてください。配布物はインストーラーとSHA-256一覧のみです。.NET Runtimeは同梱し、WebView2 Runtimeは別途必要です。EXE／インストーラーは未署名です。
