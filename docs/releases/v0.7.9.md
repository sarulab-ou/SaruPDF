# SaruPDF 0.7.9

- PDFを開いたとき、ページ幅が表示領域に収まる倍率で表示します。
- 「表示 (V)」メニューに「ページ幅を基準に表示」「1ページ」「ズームイン」「ズームアウト」を追加しました。「1ページ」は現在のページ全体が画面に収まる表示です。全モードで利用できます。
- View・ページ操作・コメントの全モード間で、切り替え直前の倍率と上下左右の表示位置を引き継ぎます。各モード内で変更した状態も次のモードに反映します。

Windows 11で自動テスト93件が成功しました。実際のPDF画面で初回の幅合わせ、全モードの表示メニュー操作、モード間の倍率・位置の引き継ぎを確認しています。Windows 10とインストーラーの導入・削除は今回未検証です。

`SaruPDF-0.7.9-Setup-x64.exe`で更新してください。更新前にSaruPDFの全ウィンドウを閉じてください。配布物はインストーラーとSHA-256一覧のみです。.NET Runtimeは同梱し、WebView2 Runtimeは別途必要です。EXE／インストーラーは未署名です。
