# SaruPDF 0.7.2

- 起動時のViewモードを追加し、編集メニューからView・ページ操作・コメントの各モードを切り替えられるようにしました。
- コメントモードでマウスドラッグによる文字選択と、右クリックからのコメント追加に対応しました。キーボードによる選択とEnterでの追加も利用できます。
- SaruPDFで作成した保存済みコメントを、クリックまたは右クリックから編集できます。Undo・Redoと再保存にも対応します。
- 英語の赤字コメントが表示されない問題を修正しました。赤字は10 ptの明朝体とし、先頭をハイライトに合わせ、ページ右端で折り返します。極端に右端に近い場合は文字の幅を確保するため左に寄せます。
- ビューアーの吹き出しマークを抑え、コメント本文をPDF標準のFreeText注釈に保持します。旧版のSaruPDFコメントは編集して保存するか、コメントモードで名前を付けて保存すると表示が更新されます。他のビューアーでの表示は異なる場合があります。
- 新しいスクリーンショットを掲載し、READMEの使い方を整理しました。

Windows 11でビルドは警告・エラー0、自動テスト76件が成功しました。英語・日本語の保存後の赤字、コメント編集、選択、回転したページでの位置と折り返しを確認しています。Windows 10と他のPDFアプリでの対話的な編集は未検証です。画像だけのPDFの文字選択、コメント削除、他のアプリで作成した注釈の編集は未対応です。

`SaruPDF-0.7.2-Setup-x64.exe`で更新してください。更新前にSaruPDFの全ウィンドウを閉じてください。配布物はインストーラーとSHA-256一覧のみです。.NET Runtimeは同梱し、WebView2 Runtimeは別途必要です。EXE／インストーラーは未署名です。
