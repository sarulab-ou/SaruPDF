# SaruPDF 0.7.20

- ページ操作モードで、右クリックの「削除」またはDelete（Del）キーから選択ページを削除できるようにしました。複数ページをまとめて削除できます。
- Ctrl+Zで元に戻し、Ctrl+Yでやり直せます。削除したページのSaruPDFコメントと回転も復元します。コピー済みのページは保持します。
- 1ページ以上残す必要があるため、全ページを選択しているときは削除を無効にします。切り取り中も無効にし、検索欄・アドレスバー・コメントモードのDeleteキーではページを削除しません。

Windowsで自動テスト114件が成功しました。複数ページの削除・保存、残存コメントとしおり参照、Undo/Redo、Deleteキーの入力先による動作を確認しています。Windows 10と実際のインストール先への上書き更新は今回未検証です。

初回導入用インストーラー、更新専用ZIP、それぞれのSHA-256一覧を配布します。「ヘルプ → 更新」から更新できます。
