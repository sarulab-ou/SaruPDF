# SaruPDF 0.7.1

- 新しく追加したコメントを、ハイライトに少し重なる赤字で表示します。入力直後だけでなく、保存して開き直したPDFでも表示が残ります。
- 赤字は細めの明朝体「游明朝 Light」を使用します。画面では細い線が欠けにくいよう滑らかに描画し、日本語と改行に対応します。未導入の環境では游明朝などの明朝系フォントに切り替えます。
- 赤字をPDF標準のFreeText注釈として、Highlight／Popupと同じグループへ保存します。文字のベクトル輪郭を持たせるため、フォントファイルを追加配布せず、本文を画像化しません。
- ページ端・回転・切り抜きのあるページでも赤字の位置を調整します。長いコメントは表示枠で折り返し、全文はコメント表示から確認できます。
- 原本のページ寸法と本文を保持し、Undo／Redoや再保存で注釈が重複しないことを検査しています。以前の版で保存した注釈の見た目は自動では変更しません。

ビルドは警告・エラー0、自動テスト72件が成功しました。赤字とハイライトの重なり、保存後のFreeText構造、日本語本文、ページ寸法・本文の保持を確認しています。Windows標準PDF描画と別のPDFエンジンでも保存後の表示を確認しました。

保存済みコメントの本文変更・削除、コメント同士の自動衝突回避、外部アプリでの対話的な注釈編集、Windows 10、インストーラー導入・削除の再検査は未実施です。

`SaruPDF-0.7.1-Setup-x64.exe`で更新してください。更新前にはSaruPDFの全ウィンドウを閉じてください。配布物はインストーラーとSHA-256一覧のみです。.NET Runtimeは同梱し、閲覧用のWebView2 Runtimeは別途必要です。EXE／インストーラーは未署名です。
