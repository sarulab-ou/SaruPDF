# SaruPDF 0.7.8

- コメントモードのPage Down／Page Upで、2段組の左段の上・下、右段の上・下、次／前のページの順にキャレットを移動できます。Shiftを押しながらの範囲選択にも対応します。
- Page Down／Page Up、Home／Endでキャレットが移動すると、移動先に赤い丸を一瞬表示します。この表示はPDFに保存されません。
- 2段組を判定できないページはページ単位で移動します。複雑な段組みや縦書きでは、読み順が意図どおりにならない場合があります。

Windows 11で自動テスト90件が成功しました。2段組のページ間移動、逆方向とShift選択、赤い目印の表示・消去を確認しています。Windows 10とインストーラーの導入・削除は今回未検証です。

`SaruPDF-0.7.8-Setup-x64.exe`で更新してください。更新前にSaruPDFの全ウィンドウを閉じてください。配布物はインストーラーとSHA-256一覧のみです。.NET Runtimeは同梱し、WebView2 Runtimeは別途必要です。EXE／インストーラーは未署名です。
