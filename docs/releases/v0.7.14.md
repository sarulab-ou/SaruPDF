# SaruPDF 0.7.14

- 開いているPDFが外部で保存・置換されたとき、自動で再読み込みします。現在のモード・倍率・ページ内の上下左右の位置を引き継ぎます。
- 保存途中やロック中は再試行し、不完全なPDFで現在の表示を置き換えないようにしました。
- 未保存の編集がある場合は再読み込みを保留して通知します。編集を残す場合は「名前を付けて保存」を使ってください。保存先を変えた後は、新しいファイルを監視します。

Windows 11で自動テスト104件が成功しました。実ファイルの上書き・置換、全モードの再描画と表示位置の保持、未保存編集の保護、監視先の切り替えを確認しています。Windows 10での動作と実際のインストール先への上書き更新は今回未検証です。

v0.7.12以降は「ヘルプ → 更新」からZIP方式で更新できます。初回導入用インストーラー、更新専用ZIP、それぞれのSHA-256一覧を配布します。
