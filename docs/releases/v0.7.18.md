# SaruPDF 0.7.18

- Viewモードで引用などのPDF内リンクをたどると、移動先を赤い丸で一瞬示します。
- 「ツール → 前の場所に戻る」でも戻り先を示します。マウスでクリックした引用の位置を記録し、元の倍率・表示位置へ戻った後、その位置に丸を表示します。
- コメントモードのキャレット移動時と同じ見せ方で、丸は約0.9秒後に消えます。クリック操作を妨げず、PDF本体には保存されません。

Windowsで自動テスト109件が成功しました。リンク先・戻り先の赤丸をキャプチャ画像の画素で検査し、元のクリック位置との一致、自動消去、PDF本体が変化しないことを確認しています。検索・編集・更新など既存機能の回帰試験も成功しています。Windows 10と実際のインストール先への上書き更新は今回未検証です。

初回導入用インストーラー、更新専用ZIP、それぞれのSHA-256一覧を配布します。「ヘルプ → 更新」から更新できます。
