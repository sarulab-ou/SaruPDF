# SaruPDF 0.2.2

- 数字を入力してEnterを押すと、そのページへ移動できるようにしました。例：`12`→Enterで12ページ目へ移動します。テンキーにも対応しています。
- 入力中だけ右上に案内を表示します。Backspaceで修正、Escで取り消せます。常設のPDFツールバーは非表示のままです。

`SaruPDF-0.2.2-Setup-x64.exe` で更新してください。更新前にはSaruPDFの全ウィンドウを閉じてください。配布はインストーラーとSHA256一覧のみです。
