# SaruPDF 0.7.17

- 「ツール (T) → 前の場所に戻る」を追加しました。Viewモードで引用などのPDF内リンクをたどった後、移動前のページ・倍率・表示位置へ戻れます。
- 複数のリンクをたどった場合も順に戻れます。戻れる履歴がない場合は項目を無効にします。
- 通常のスクロールは履歴に追加しません。履歴はウィンドウごとに保持し、文書の再読み込みやアプリ終了時に消去します。

Windowsで自動テスト109件が成功しました。PDF内の参照リンクを実際にクリックして、異なる倍率・位置から順に戻る操作と、検索など既存機能の回帰試験を確認しています。Windows 10と実際のインストール先への上書き更新は今回未検証です。

初回導入用インストーラー、更新専用ZIP、それぞれのSHA-256一覧を配布します。v0.7.12以降は「ヘルプ → 更新」からZIP方式で更新できます。v0.7.16からの更新では、開いていたPDFのモード・倍率・表示位置も引き継ぎます。
