# SaruPDF 0.7.0

- 「編集 → コメントモード」を追加しました。矢印キーでキャレットを移動し、Shiftを押しながら範囲選択、Enterでコメントボックスを開けます。入力後は「追加」またはCtrl+Enterで確定し、Ctrl+Sで保存します。
- コメントはPDF標準のHighlight／Popup注釈としてPDF本体へ保存します。日本語、改行、絵文字、複数ページの範囲に対応し、本文を画像化しません。コメントモードでハイライトをクリックすると、保存されているコメントを表示できます。
- コメントの追加はCtrl+Z／Ctrl+Yで取り消し・やり直しができます。モード切り替えや終了時には未保存の変更を確認します。Windows 11ではコメントモードのタイトルバーが緑色になります。
- 「編集モード」を「ページ操作モード」に変更しました。通常表示の拡大率を引き継ぎ、Windows 11ではタイトルバーが青色になります。
- ページ操作モードで↑／↓・PgUp／PgDnによるページ移動、Home／Endによる先頭・末尾への移動、Shift併用での範囲選択に対応しました。選択ページの青枠と現在ページのオレンジ枠を区別し、移動先を画面の縦中央に表示します。
- 新規ウィンドウとCtrl+N、メニューバー直下の「PDFを開く」「設定」を削除しました。PDFを開く操作はファイルメニューとCtrl+Oから利用できます。別PDF間のページコピーや境界からのPDFインポートは引き続き利用できます。

ビルドは警告・エラー0、自動テスト70件が成功しました。コメントの文字選択・入力・キャンセル・Undo/Redo・保存、標準注釈の構造、日本語本文、回転・切り抜きページの座標を検査しています。保存後のハイライトをWindows標準PDF描画と別のPDFエンジンで確認しました。

画像だけのPDFには文字情報がないため、キャレット選択できません。OCR、保存済みコメントの本文変更・削除は未対応です。複雑な縦書き・段組み、Acrobat等での対話操作、Windows 10、PDF/A・PDF/UA適合性、インストーラー導入・削除の再検査は未実施です。

`SaruPDF-0.7.0-Setup-x64.exe`で更新してください。更新前にはSaruPDFの全ウィンドウを閉じてください。配布物はインストーラーとSHA-256一覧のみです。.NET Runtimeは同梱し、閲覧用のWebView2 Runtimeは別途必要です。EXE／インストーラーは未署名です。
