# SaruPDF 0.2.1

- 関連付け画面を単独起動したときに「閉じる」ボタンが反応しない不具合を修正しました。
- ページ番号などが並ぶ PDF ツールバーの行を非表示にしました。
- 文書ウィンドウのタイトルを「ファイル名（フルパス）」に変更しました。
- 赤（RGB 255, 0, 0）の「PDF」アイコンを EXE、ウィンドウ、セットアップに組み込みました。

`SaruPDF-0.2.1-Setup-x64.exe` で更新してください。更新前には SaruPDF の全ウィンドウを閉じてください。配布はインストーラーと SHA256 一覧のみです。

ビルドは警告・エラー 0、自動テスト 26 件が成功しました。Windows 11 でツールバー行の非表示、タイトル、アイコン、および単独起動した関連付け画面の「閉じる」ボタンによるプロセス終了を確認しました。

.NET Runtime は同梱、WebView2 Runtime は別途必要です。EXE／インストーラーは未署名です。
