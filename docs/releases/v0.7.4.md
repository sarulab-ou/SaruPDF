# SaruPDF 0.7.4

- メニューの下にアドレスバーを追加し、開いているPDFのフルパスを表示します。パスを選択してコピーでき、名前を付けて保存すると新しい保存先に更新されます。
- Alt+Dでアドレスバーに移動し、パスを全選択します。View・ページ操作・コメントの各モードで使用できます。
- バーにフォーカスがあるときは、Ctrl+AとCtrl+Cをパスの選択・コピーに使用します。ページ番号などのPDFツールバーは引き続き非表示です。

Windows 11で自動テスト81件が成功しました。パスの表示・別名保存時の更新と、各モードでのAlt+Dを確認しています。Windows 10とインストーラーの導入・削除は今回未検証です。

`SaruPDF-0.7.4-Setup-x64.exe`で更新してください。更新前にSaruPDFの全ウィンドウを閉じてください。配布物はインストーラーとSHA-256一覧のみです。.NET Runtimeは同梱し、WebView2 Runtimeは別途必要です。EXE／インストーラーは未署名です。
