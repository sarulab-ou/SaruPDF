# SaruPDF 0.4.0

- 編集モードの左側の一覧・ボタン列をなくし、PDF本文上で直接ページを選択する画面に変更しました。
- Ctrl+クリックで離れた複数ページを追加・解除、Shift+クリックで範囲選択、Ctrl+Aで全選択できます。
- Ctrl+Xまたは右クリックで切り取り、ページとページの隙間を右クリック→「ここに貼り付け」で、元の順番を保ってまとめて挿入できます。ページ上のメニューからは、そのページの前・後にも貼り付けられます。
- Ctrl+ホイールや右クリックメニューで拡大・縮小できます。数字＋Enter、Undo/Redo、保存・別名保存にも対応します。

同じPDF内のページ移動に対応します。表示にはWindows標準のPDF描画APIを使用し、保存時は元のPDFのページ参照を並べ替えます。PDF本文を画像化して保存することはありません。文字の選択・コピーやリンク操作は閲覧モードで行ってください。

ビルドは警告・エラー0、自動テスト45件が成功しました。直接選択とページ間メニュー、保存後の実描画、リサイズ・ズーム、複数ページの順序・全ページ切り取りからの復元を確認しています。物理マウスによる実デスクトップ上の通し操作、Windows 10での確認、インストーラー導入・削除の再試験は未実施です。

`SaruPDF-0.4.0-Setup-x64.exe`で更新してください。Windows 10（1809以降）/ 11 x64が必要です。更新前にはSaruPDFの全ウィンドウを閉じてください。配布はインストーラーとSHA256一覧のみです。.NET Runtimeは同梱、閲覧モードのWebView2 Runtimeは別途必要です。EXE／インストーラーは未署名です。
