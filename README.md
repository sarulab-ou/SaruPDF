# SaruPDF

Windows向けのPDF Viewer・ページ編集アプリです。1文書につき1つのウィンドウが開きます。同じPDFをもう一度開くと、既存のウィンドウへ移動します。ページ番号などのツールバーを省き、文書を広く表示します。

**[ダウンロード（Windows x64・インストーラー.exe）](https://github.com/sarulab-ou/SaruPDF/releases/download/v0.7.1/SaruPDF-0.7.1-Setup-x64.exe)** · [使い方](#使い方) · [開発・ビルド](docs/development.md)

_SaruPDF v0.2.1の実画面。自動テストで生成した検証用PDFを表示しています。_

## できること

- **1文書、1ウィンドウ。** PDFを好きな位置に並べて使えます。移動・サイズ変更・最小化・最大化をそれぞれ操作でき、Alt+Tabやタスクバーから選べます。タブはありません。
- **同じPDFは同じウィンドウへ。** アプリ内から開く場合も、Explorerなどから追加起動した場合も、既存の文書へ移動します。最小化中なら復元し、現在のページやズームは保持します。
- **文書を広く表示。** ページ番号などのPDFツールバー行は非表示です。スクロールに加え、数字を入力してEnterを押すと指定ページへ移動できます。
- **PDF画面で直接ページを編集。** 「編集 → ページ操作モード」で本文上のページをクリックして選択します。Ctrl／Shiftで複数選択し、ページ間を右クリックしてまとめて移動できます。左側のページ一覧は表示しません。
- **本文にコメントを付ける。** 「編集 → コメントモード」でキャレットを動かし、Shiftで文字範囲を選択、Enterでコメントを入力します。PDF標準のハイライト注釈として保存します。
- **別のPDFからまとめてコピー。** 選んだ複数ページをCtrl+Cでコピーし、別のPDFへまとめて貼り付けられます。コピー元のPDFは変更しません。
- **ファイルの場所が分かる。** タイトルは「ファイル名（フルパス）」です。下端のパス欄からも確認・コピーできます。
- **PDFを開くアプリとして登録。** インストール時、またはスタートメニューの「SaruPDF → PDF の関連付け」から、Windowsの「プログラムから開く」の候補に登録できます。
- **日本語や空白を含むパスに対応。** 複数のPDFをまとめて渡せます。同名でも異なるフォルダーのPDFは別の文書として開きます。

## ダウンロード・インストール

**[SaruPDF v0.7.1 Windows x64インストーラーをダウンロード](https://github.com/sarulab-ou/SaruPDF/releases/download/v0.7.1/SaruPDF-0.7.1-Setup-x64.exe)**

[リリースノート](https://github.com/sarulab-ou/SaruPDF/releases/tag/v0.7.1) · [SHA-256チェックサム](https://github.com/sarulab-ou/SaruPDF/releases/download/v0.7.1/SaruPDF-0.7.1-SHA256SUMS.txt) · [ソースからのビルド](docs/development.md)

1. `SaruPDF-0.7.1-Setup-x64.exe`をダウンロードし、**Windows 10（1809以降）/ 11 x64**で実行します。現在のユーザー用にインストールするため、管理者権限は不要です。
2. **WebView2 Runtimeが必要です。** インストーラーには含まれません。不足している場合は、アプリが案内する[Microsoft公式サイト](https://developer.microsoft.com/microsoft-edge/webview2/#download-section)からEvergreen Runtime（x64）をインストールし、SaruPDFを再起動してください。.NET Runtimeは同梱しています。
3. `.pdf`をダブルクリックで開きたい場合は、Windowsの既定アプリ設定でSaruPDFを選択します。完了画面の「PDF の関連付け設定を開く」から設定できます。

更新する場合は、SaruPDFの全ウィンドウを閉じてからインストーラーを実行してください。保存先の既定値は`%LOCALAPPDATA%\Programs\SaruPDF`です。

配布するEXEとインストーラーは未署名です。Windows 11での実画面確認と自動テストを実施しています。Windows 10・WebView2未導入PCでの受け入れ確認は未完了です。[検証記録](docs/verification.md)を参照してください。

リポジトリとリリースは公開しており、GitHubへのログインなしでダウンロードできます。

## 使い方

1. スタートメニューの**SaruPDF**を起動します。
2. **「PDF を開く」またはCtrl+O**でファイルを選びます。複数選択もできます。最初のPDFは、起動時の空ウィンドウに表示します。
3. 文書をスクロールして読みます。**数字を入力してEnter**でもページを移動できます。たとえば`12`→Enterで12ページ目へ移動します。入力中だけ右上に案内が出ます。Backspaceで修正、Escで取り消せます。別のPDFを開くと、新しいウィンドウに表示します。すでに開いているPDFなら、そのウィンドウへ移動します。
4. **Ctrl+W**で現在のウィンドウだけを閉じます。ほかの文書は残り、最後のウィンドウを閉じるとアプリが終了します。

PDFの右クリックから「プログラムから開く」→「別のプログラムを選択」→**SaruPDF**でも開けます。候補にない場合は、インストール先の`SaruPDF.exe`を指定してください。

## ページを編集する

1. PDFを開き、**「編集 (E) → ページ操作モード」**を選びます。通常表示の拡大率を引き継ぎ、PDF本文を連続表示したまま直接操作できます。Windows 11ではタイトルバーが青色になります。
2. 本文上のページをクリックすると青枠で選択します。**Ctrl+クリック**で離れたページを追加・解除、**Shift+クリック**で範囲選択、**Ctrl+A**で全ページを選択できます。**↑／↓・PgUp／PgDn**で前後のページ、**Home／End**で先頭・末尾へ移動します。**Shift**を押しながら移動すると、起点からの選択範囲を広げたり縮めたりできます。選択ページは青枠と「選択中」、現在ページはオレンジの内枠と「現在のページ」の表示で区別し、移動したページを画面の縦中央に表示します。
3. **Ctrl+X**、または選択ページの右クリックメニューで切り取ります。挿入したい**ページとページの隙間を右クリック →「ここに貼り付け」**で挿入します。先頭の上・最後の下でも貼り付けられます。ページ上のメニューからは「このページの前／後に貼り付け」も選べます。Ctrl+Vは選択した挿入位置へ貼り付けます。
4. **Ctrl+S**で上書き保存、**Ctrl+Shift+S**で名前を付けて保存します。保存するまでは元のPDFを変更しません。

複数ページを切り取った場合も、元のページ順を保ってまとめて挿入します。**Ctrl+Z**で元に戻し、**Ctrl+Y**でやり直せます。切り取り中のページは、貼り付けるまで保存できません。**Ctrl+「+」／Ctrl+「-」**、Ctrl+ホイール、右クリックメニューで拡大・縮小でき、数字＋Enterで指定ページへ移動できます。テンキーの＋／－や、＋の入力にShiftが必要なキーボードにも対応します。

ページ操作モードを解除するときやウィンドウを閉じるとき、未保存の変更があれば保存するか確認します。編集中に元ファイルが別のアプリで変更された場合は、上書きせず、名前を付けて保存してください。別名で保存すると、その保存先が現在の文書になります。

### 別のPDFからページをコピーする

1. コピー元・貼り付け先のPDFをSaruPDFで開き、**両方をページ操作モード**にします。
2. コピー元でページを選択します。**Ctrl+クリック／Shift+クリック**で複数選択できます。
3. **Ctrl+C**、または右クリックの**「選択した○ページをコピー」**を選びます。
4. 貼り付け先の**ページ間を右クリック →「ここに貼り付け」**で、元の順番を保ってまとめて挿入します。ページ上のメニューから前・後へ挿入したり、挿入位置を選んでCtrl+Vを使ったりできます。
5. 貼り付け先を**Ctrl+S**で保存します。別名で残す場合はCtrl+Shift+Sです。

コピー元は変更しません。コピーした後は元のウィンドウを閉じても貼り付けられ、同じページを繰り返し貼り付けたり、同じPDF内に複製したりできます。貼り付けはCtrl+Zで元に戻せます。

コピーしたページはSaruPDF内の専用クリップボードで共有し、アプリを終了すると消去します。Windowsのテキスト用クリップボードや、他のPDFアプリとのページ受け渡しは使用しません。切り取りは同じPDF内の移動です。切り取り中のページがある場合は、そちらの貼り付けを先に完了します。暗号化・パスワード付きPDFや署名欄のあるPDFの編集には対応していません。

ページ操作モードではページを画像として表示します。文字の選択・コピーや文書内リンクの操作は、ページ操作モードを解除して行ってください。保存するPDF自体は画像化しません。

### PDFをインポートする

ページ操作モードで**ページとページの境界を右クリック →「ここにPDFをインポート…」**を選ぶと、その位置へ選んだPDFの**全ページ**を挿入します。複数のPDFをまとめて選べます。複数ファイルのインポートもCtrl+Zで一度に元に戻せます。読み込めないPDFが含まれる場合は、全体を挿入せずにエラーを表示します。インポート元のPDFは変更しません。

## 本文にコメントを付ける

1. PDFを開き、**「編集 (E) → コメントモード」**を選びます。Windows 11ではタイトルバーが緑色になります。通常表示の拡大率を引き継ぎます。
2. 本文をクリックしてキャレットを置くか、**←／→**で文字単位、**↑／↓**で行単位に移動します。**Home／End**で行頭・行末、**Ctrl+Home／End**で文書の先頭・末尾、**PgUp／PgDn**で前後のページへ移動します。
3. **Shiftを押しながら移動**すると、その範囲を青色で選択します。Shift+クリックやCtrl+Aでも選択できます。
4. 選択中に**Enter**を押すとコメントボックスが開きます。コメントを入力し、**「追加」またはCtrl+Enter**で確定します。ボックス内のEnterは改行です。Esc／キャンセルでは文書を変更しません。
5. **Ctrl+S**で保存します。元のPDFを残す場合はCtrl+Shift+Sです。保存前の追加はCtrl+Zで取り消し、Ctrl+Yでやり直せます。

新しく追加したコメントは、**ハイライトに少し重ねた赤字**で表示します。赤字には細めの明朝体「游明朝 Light」を使います。保存後も赤字が残ります。コメントは**PDF標準のHighlight（ハイライト）・Popup・FreeText注釈**としてPDF本体に保存します。選択範囲の座標、コメント本文、日本語、作成日時を持ち、本文を画像化しません。複数ページの範囲にはページごとに注釈を追加します。コメントモードでハイライトをクリックすると、そのコメントを表示できます。保存後は対応する他のPDFビューアーでも扱える形式です。コメント一覧や吹き出しの表示方法はビューアーにより異なります。長い赤字コメントは表示枠で折り返し、入りきらない本文はクリックして全文を確認できます。以前の版で保存した注釈の見た目は自動では変更しません。

本文の文字情報を使用するため、**画像だけのスキャンPDFではキャレット選択できません**。OCRは行いません。複雑な段組み、縦書き、文字情報が正しくないPDFでは読み順や選択範囲が一致しない場合があります。今回の版ではコメントの追加・閲覧に対応し、保存済みのコメント本文の変更・削除は未対応です。

ページ操作モードとコメントモードは切り替えて使用します。未保存の変更がある状態でモードを解除・変更・終了すると、保存するか確認します。

## PDFの関連付け

インストーラーの「PDF を開くアプリの候補に登録」は初期状態で選択されています。スタートメニューの**「SaruPDF → PDF の関連付け」**からも登録できます。

既定のPDFアプリにするには、**「登録して Windows の既定アプリ設定を開く…」**を押し、Windowsの画面で`.pdf`のアプリとしてSaruPDFを選択します。候補登録だけでは、現在の既定アプリを変更しません。

アンインストールはWindowsの「インストールされているアプリ」から行えます。SaruPDFを既定にしていた場合は、Windowsの画面で次のPDFアプリを選択してください。

## コマンドから開く

インストール先をカレントディレクトリにした場合の例です。

```powershell
.\SaruPDF.exe "C:\Documents\論文 A.pdf"
.\SaruPDF.exe "C:\Documents\論文 A.pdf" "C:\Documents\論文 B.pdf"
```

相対パスは起動元のカレントディレクトリを基準に解決します。引数なしで追加起動した場合は、既存のウィンドウへ移動します。

## ファイルの扱いと制限

- PDFはローカルで表示し、SaruPDFが文書を外部サービスへアップロードする処理はありません。WebView2自身の更新・ネットワーク動作はMicrosoftの製品仕様に従います。
- 本文の文字・画像の編集、ページの削除、保存済みコメントの変更・削除は未実装です。ページ操作モードはページの並べ替えと、同じPDF・別のPDFへのページコピーに対応します。
- 別PDFからのコピーでは、コピー元の文書全体のしおりやフォーム構造は移植しません。複雑な注釈やページ間リンクの完全保持は未検証です。貼り付け先の文書情報を維持します。
- ページの内容・回転・基本的な注釈・しおりの参照先を保持する試験を実施しています。特殊なフォーム、PDF/A・PDF/UA、ページラベルなど全機能の保持は検証していません。
- 同じPDFかどうかは、正規化した完全パスで判定します。シンボリックリンク・ハードリンク・短縮名など、別名を経由した同一判定は未対応です。
- 外部アプリが同じパスのPDFを置換しても、既存ウィンドウを優先します。最新版を表示するには、そのウィンドウを閉じて開き直してください。
- 数字＋Enterのページ移動時はPDFを再表示します。ズームなどの表示状態や、総ページ数を超える番号の扱いはWebView2に依存します。
- 文書の置き換えを防ぐため、表示領域への外部ドラッグ＆ドロップは無効です。破損・暗号化・特殊なPDF機能への対応はWebView2に依存します。
- 通常権限での使用を前提とします。管理者権限と通常権限を混在させると、追加起動の引き継ぎができない場合があります。

## 開発

C#、.NET 10、Windows Forms、Microsoft Edge WebView2で実装しています。Windows x64、PowerShell 7以降、.NET 10.0.403 SDKが必要です。

```powershell
.\scripts\Build.ps1
.\scripts\Test.ps1
```

SDKやインストーラー用ツールの準備、配布用ビルド、GitHub Releasesへの掲載は[開発・ビルドガイド](docs/development.md)を参照してください。自動テストは72件で、倍率の引き継ぎ・PDFインポート・拡大縮小キー・PDF間コピー・保存・元ファイル保護と実際のPDF描画を検査します。
